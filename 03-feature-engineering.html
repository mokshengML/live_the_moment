Feature Engineering — Lesson 03
No-Code Interactive Lesson

Don't just feed the model — teach it what to look at

Feature engineering is the quiet superpower that separates working models from useless ones. Same data, same algorithm — but with thoughtfully crafted features, accuracy can jump 20–30%. In this lesson you'll shape four kinds of features by hand, and feel why each matters.

⚡

The Case: Forecasting tomorrow's electricity demand

A power utility wants to predict tomorrow's load so they can buy energy efficiently. Raw timestamps and a number won't cut it. You'll engineer features that capture yesterday's load, weekly trends, the day of the week, the season, and the holiday calendar — the same recipe used by Netflix, Swiggy, and Uber.

1
Lag features — yesterday's value, today's prediction

A lag feature is "the value from N steps ago, added as a new column on today's row." Why? Because most real-world data has memory. Yesterday's electricity demand is the single best predictor of today's. A model can't "see" history unless you hand it history as a feature — that's all a lag does.

Analogy: Imagine asking a friend to predict tomorrow's temperature with no information. Hopeless. Now hand them today's temperature — much easier. Lag features are how you hand "yesterday's temperature" to your model.

2
Rolling averages — smooth out the noise

Daily numbers are jittery. A rolling (or moving) average replaces each day with the average of the last N days. The wiggle disappears; the trend appears. As a feature, it tells your model "the level for the past week" instead of "what happened on a single noisy day."

Analogy: A single day's weight on the scale is misleading (you drank water, you wore jeans). The weekly average is your actual weight. Rolling averages do the same job for any time series.
▶ Try it — Adjust the window, watch the noise disappear

Blue line = raw daily demand. Orange line = rolling average. Widen the window → smoother but slower to react. Too narrow → still noisy. Too wide → misses recent shifts. The sweet spot depends on how quickly your system can change.

7
Trade-off: A 7-day rolling average is a classic default — long enough to smooth daily wiggle, short enough to react to real weekly shifts. For monthly trends try 30. For hourly metrics, try 24.
3
Date-time decomposition — one date, ten features

A date like "2026-03-21" is useless to most algorithms as text. But that single string secretly contains a dozen useful signals: weekday, month, quarter, season, is-it-a-weekend, is-it-a-holiday, days-since-start, week-of-year. Each becomes its own column. This single trick rescues most time-series projects.

Analogy: A passport is "one document" but it contains nationality, age, gender, expiry — each useful for different purposes. Date-time decomposition opens the passport.

The big idea: Each feature here is a hypothesis. "Maybe weekday matters." "Maybe holidays matter." Decomposition lets the model decide — it'll learn which ones predict and ignore the rest.
4
One-hot encoding — turning words into numbers

Algorithms can't multiply by "Monday." They can multiply by 1. One-hot encoding takes a categorical column (Monday, Tuesday…) and replaces it with one new column per category, each filled with 0 or 1. Now the math works — and the model can learn a different coefficient for each category.

Analogy: Filling a form. Instead of writing your blood group as text, you tick one of the boxes: ☑A+ ☐B+ ☐O+ ☐AB+. Each tick-box is one feature; only one is "on" at a time. That's one-hot.
▶ Try it — Encode the "Day of week" column

Left: original categorical column. Right: same data, one-hot encoded. Click any row to highlight which box "fires." This is exactly what pd.get_dummies() does in Pandas.

Watch for: A column with 7 unique days becomes 7 new columns. Now imagine a column with 10,000 unique product IDs — one-hot would create a 10,000-wide table. That's why "high-cardinality" categories need different tricks (target encoding, embeddings) which you'll meet in the deep-learning module.

🌱 Four feature techniques that quietly run the world

Every forecast you've ever trusted — power grids, delivery ETAs, weather, fraud alerts — runs on engineered features like these. The model is the chef; the features are the ingredients. Better ingredients beat fancier recipes.
